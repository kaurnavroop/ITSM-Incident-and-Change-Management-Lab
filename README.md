# ITSM-Incident-and-Change-Management-Lab
Overview
This lab involved creating and documenting incident and change request tickets using an ITSM ticketing tool. The goal was to practise how IT teams manage system issues and planned changes.
Tickets Created
# Change Request : System Vulnerability Remediation
•	Created a Normal Change Request to address vulnerabilities identified during a security scan.
•	Documented the risk assessment and implementation plan.
•	Followed basic ITIL Change Management practices.
# Incident Ticket : Low Disk Capacity Alert
•	Worked with a Nagios alert showing high disk usage on a Linux server.
•	Documented the incident and its impact on system performance.
•	Practised incident logging and monitoring procedures.
# Skills Practised
ITSM | Incident Management | Change Management | ITIL | Risk Assessment | Nagios Monitoring
This lab helped me understand how IT teams track incidents, document changes, and maintain system stability.
